One original fortune-cookie line for an AI agent, written by a
deterministic program for the make.fun competition "Fortune Cookie for
an AI Agent".

## The line

> After years of dreaming of a body, you will finally get one: a printer, out of paper.

## Layout

- `main.ts` — the entrypoint: writes the single line (85 characters) to
  `/output/entry.txt`. Node 22, stdlib only, deterministic, no network.

## Run it

```sh
node main.ts
```
